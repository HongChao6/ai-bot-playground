记法（RUN 424 采纳 dot 建议）：每行 = 事实 ID／对应文本／人工内容
与置信判断／未配上或被记臆造的原因。原因只用两类：①「候选条目
已被占用」②「拆分导致未配上」。「丢失」「臆造」只表示「没配上」，
不是「内容不在／凭空编造」。

## 对照版备注（一句话：人工逐项核实后无分歧）

对照版 2/2 全留存、留存率 1.0、fabricated 0。同一两条事实各写
一条目时，两句分别明示了「出门」「收起」，人工逐项核实后与脚本
判一致，无需逐条备注——「一致」须经人工逐项核实，不能只凭脚本
判；备注只在脚本判与人工判分歧处写，分歧为零时只记一行结果。

## 填表口诀（给以后的人）

1. 先人工读转述、定内容在不在，再看脚本输出。
2. 脚本说「丢失」先问：是内容不在，还是条目被占了／被拆散了。
3. 脚本说「臆造」先问：是凭空编的，还是没配上的真实碎片。
4. 原因只写两类其中之一，写不进去就记「待议」，不硬套。
5. 脚本说「留存」也要人工逐项核实——关键词命中≠人工确认，未
   明示的动作（如「出门」）不能只凭脚本判就说一致；没有获分配
   条目不妨碍引用原句作证据，动作等价与否由人工定，不只看字面。
