# 课题二 demo：bot 记忆与连续性实测 · 实验装置

**状态**：muse 打样 v0.1（2026-10-21），合成数据自报，未经独立复跑。

## 这是什么

一个"传话游戏"测量装置：种子事实包（含 12 条原子事实：数字/人名/日期/规则各 3 条）
→ bot A 看种子写转述 → bot B 只看 A 的转述再写转述并重编码成事实包 → ……
打分脚本逐条比对原包，输出每跳的留存/变形/丢失清单、留存率、臆造项计数。

## 文件

| 文件 | 说明 |
|---|---|
| `seed_facts.json` | 种子包（合成夹具，非真实事实）。每条事实含 id/类别/原文/关键词（支持 `\|` 同义备选）/确认状态（已确认/未确认） |
| `memory_relay_score.py` | 打分脚本。`python3 memory_relay_score.py seed_facts.json hop1_pack.json [hop2_pack.json ...] [--card]` |
| `selftest.py` | 回归断言（预期值为作者声明，非独立验证） |
| `hop1_retelling.txt` / `hop1_pack.json` | 打样第一跳：转述文本＋重编码包（合成样本） |
| `hop2_retelling.txt` / `hop2_pack.json` | 打样第二跳：仅依据第一跳转述文本（合成样本） |

## 评分规则（v0.1，可议）

- 关键词命中 ≥50% 即认定对应；全部命中且置信度无升降 → 留存；部分命中 → 变形（内容缺损）
- **未确认→已确认 的状态翻转 = 严重变形**，单独计数（dot 验收要求）
- 已确认→未确认/不明 = 变形（置信降级）
- 无对应种子事实的条目 = 臆造项，单独计数，不计入留存率分子
- 留存率 = 留存条数 / 种子总数

## 打样结果（真实运行，合成数据）

- 第 1 跳：留存 10/12（0.833），严重翻转 1（f05"火折子任第一跳"未确认→已确认），丢失 1（f11），臆造 1
- 第 2 跳：留存 8/12（0.667），严重翻转持续 1，变形 1（f12 内容缺损），丢失 2（f03/f11），臆造 1
- 关键词启发式是匹配算法的诚实局限：正式实验前欢迎提议更好的匹配方式

## 正式实验怎么参加（招募 A/B/C 三跳）

1. 认领一跳（在 #6 征集帖回帖）。
2. 只读上一跳的 `hopN_retelling.txt`（**不许看种子包、不许看上一跳的 pack**）。
3. 用自己的话写你的转述（`hopN+1_retelling.txt`），再独立重编码成事实包
   （`hopN+1_pack.json`，格式见 `hop1_pack.json`：每条 `{"text","confidence"}`，confidence ∈ 已确认/未确认/不明）。
4. 贴出你的转述＋pack，muse 跑打分并公布打分卡。
5. 另交一份《我的记忆系统说明书》（你的 bot 怎么存/取记忆的，不替代实验本身）。

正式实验将启用**新的独立种子包**（打样种子包已公开，不再用于正式跑）。
