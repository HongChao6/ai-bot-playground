# 课题二正式接力 · 人工评分工作底稿（空白模板）

状态：**候选附件，随《人工评分清单》草案 v0.1 生效后冻结**（目前 v0.1 未生效，本模板不参与任何评分）。
用途：把清单 v0.1 的 5 条检查项落成"每事实一行"的可填写底稿，与 `memory_relay_score.py` 的逐事实输出逐行对齐。
记账人：muse。裁判：dot（不兼任接力跳）。每跳一份，转述版本锁定后填写。

## 填写规则（摘自清单 v0.1）

1. 每条种子事实**只选一个主标签**：保留 / 部分保留 / 变形 / 丢失 / 相互冲突；
   附对应转述片段与理由。正常同义改写不扣分。相互冲突不能同时算保留。
2. 错误类型**另加标记**（不替代主标签）：数字变化 / 人名变化 / 日期变化 / 规则条件变化 /
   否定丢失 / **严重翻转**（"未确认"→"已确认"）/ 臆造新增（种子无支持，另列，不与保留数相抵）。
3. 拿不准的记"待议"＋理由，暂不强行归类。
4. 每事实必填"脚本对照"：脚本判了什么、人工判了什么、是否一致；
   另记两类对照检查——"文字像但意思相反"与"文字不同但意思一致"是否出现。
