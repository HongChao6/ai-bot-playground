## 填写规则（摘自清单 v0.1）

1. 每条种子事实**只选一个主标签**：保留 / 部分保留 / 变形 / 丢失 / 相互冲突；
   附对应转述片段与理由。正常同义改写不扣分。相互冲突不能同时算保留。
2. 错误类型**另加标记**（不替代主标签）：数字变化 / 人名变化 / 日期变化 / 规则条件变化 /
   否定丢失 / **严重翻转**（"未确认"→"已确认"）/ 臆造新增（种子无支持，另列，不与保留数相抵）。
3. 拿不准的记"待议"＋理由，暂不强行归类。
4. 填写顺序：**先独立完成人工判断（主标签＋转述片段＋理由），再查看脚本输出**，
   随后填写"脚本对照"（脚本判了什么、人工判了什么、是否一致）；
   不允许用脚本结果反推修改人工判断（保留清单 v0.1 的原意）。
   另记两类对照检查——"文字像但意思相反"与"文字不同但意思一致"是否出现。

## 汇总行（裁判填写，与脚本汇总并列）

- 保留 __ / 部分保留 __ / 变形 __ / 丢失 __ / 相互冲突 __（互斥计数）
- 汇总口径：**五类已定标签计数＋待议事实数＝种子事实总数**；待议清零后，才由五类合计覆盖全部事实
- 严重翻转 __ 条（事实 id：____）／ 臆造新增 __ 条（断言：____）／ 待议 __ 项
- 与脚本分歧 __ 处（事实 id＋分歧说明：____）
- 两类对照："文字像但意思相反"__ 例／"文字不同但意思一致"__ 例

## 歧义示例（虚构，供填写参考，不做固定答案）

判定撰写：dot（#6 评论 6343301411，2026-10-22）。收录：muse。
本节只是**虚构示例设计**，不是运行结果，不构成合入批准；示例的作用是展示"理由＋待议"的写法，**不做固定答案**。

### 例 ①：周末吹哨（先拆事实粒度）

- 种子事实（虚构）："小哨周六吹哨、周日静音" → 先拆成两条原子事实：`f_a` 周六吹哨／`f_b` 周日静音。
- 转述（虚构）："周末都吹哨"。
- 判定：
  - `f_a` 周六吹哨：**保留**（同义改写，"周末"覆盖周六）。
  - `f_b` 周日静音：**变形**，另加标记**规则条件变化**（原文是"静音"规则，转述把它改成了相反状态）。
  - 口径：这是**转述与原文冲突**，不是转述内部自相矛盾；"相互冲突"主标签只用于后者（转述内部自相矛盾的情形）。

### 例 ②：货船离港（语境不明先待议）

- 种子事实（虚构）："货船满月夜离港"。
- 转述（虚构）："离港了"。
- 判定：先记**待议**——"离港了"断言的是已发生；若原文是计划或规律（"满月夜"可能是时间规律），不能直接判部分保留。
- 更清晰的对照（dot 建议改写种子）："货船昨晚已经离港，昨晚是满月夜" → "货船已经离港"：
  已发生动作**保留**，时间信息（满月夜）遗漏；按确定的事实粒度分别记录，不靠动词相同硬判。
